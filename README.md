### Projects

| Project | What | Key result |
|---|---|---|
| [**Sequential Pattern Mining Benchmark**](https://github.com/BlayTeuR/Benchmark_SP_SPMF) | Rigorous JVM benchmark of 5 algorithms (GSP, SPADE, SPAM, CM-SPAM, PrefixSpan) on 4 datasets, plus behavioural mining of LastFM | CM-SPAM is up to **8.5× faster** than SPAM with **≤ 410 MB** peak memory; the report also documents negative results |
| [**Big Data: Dask & Ray**](https://github.com/BlayTeuR/Big-Data) | Distributed batch inference on **3M taxi trips** (Dask) and a **Ray-parallelised RAG** pipeline (MiniLM + FAISS + Flan-T5) | 1,881 chunks embedded in 38 parallel batches; grounded QA works end to end |
| [**CNN: marine species**](https://github.com/BlayTeuR/Animals_classification_using_CNN) | 3-class CNN trained from scratch (Keras), 12k images | **91.9 % test accuracy**, macro-F1 0.919 |
| [**Tweet sentiment**](https://github.com/BlayTeuR/ML_positive_or_negative_tweet_rating) | Lexicon features and 5 tree ensembles on 100k tweets, with error-driven feature engineering | **69.4 %** accuracy (majority baseline 56.5 %); precision raised from 0.685 to 0.703 |
| [**Convolutional autoencoder**](https://github.com/BlayTeuR/Autoencodeur) | Unsupervised representation learning with a linear-probe evaluation and t-SNE | Linear probe **+5.6 pts** over raw pixels |
